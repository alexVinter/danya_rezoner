# Сайт Дани: прототипы для разработки

Здесь три готовые страницы в HTML, картинки к ним, скриншоты и два ТЗ. Этого хватит, чтобы собрать сайт с нейросетью или руками.

## Что в архиве

| Что | Зачем |
| --- | --- |
| `prototype/` | три страницы: `index.html` (главная), `telegram-ads.html` (страница услуги), `case-extern.html` (страница кейса). Открываются двойным кликом, ссылки между ними работают, картинки лежат в `prototype/assets/` |
| `docs/tz-1-design-code.md` | дизайн-код: цвета, шрифт, сетка, компоненты, где какой рисунок |
| `docs/tz-2-structure.md` | порядок блоков на главной и что в каждом из них |
| `screens/` | скриншоты, порезанные по секциям. `desktop` снят на ширине 1440 px, `mobile` на 390 px, по три куска на картинке |
| `illustrations/` | рисунки в PNG 1400 px с прозрачным фоном, если понадобятся другие размеры или форматы |
| `PROMPT.md` | готовый промпт для GPT или Gemini |

## Как собрать сайт с нейросетью

1. Открой `prototype/index.html` в браузере и пролистай все три страницы. Результат должен выглядеть так же.
2. Впиши свой стек в первую строку промпта в `PROMPT.md`.
3. Открой новый чат в GPT или Gemini. Прикрепи три HTML из `prototype/`, оба `.md` из `docs/` и скриншоты главной (`index-desktop-*` и `index-mobile-*`). Вставь промпт.
4. Сначала попроси план: папки, компоненты, где лежат данные. Потом собирайте по одной странице, начиная с главной. Когда дойдёте до услуги и кейса, приложи их скриншоты.

Если чат не принимает столько файлов сразу, первыми отправь HTML и ТЗ. В них вся вёрстка и все тексты, а скриншоты нужны модели, чтобы видеть страницу целиком.

## Что важно

- Прототип задаёт внешний вид. Стили в нём для скорости написаны прямо в разметке, в коде их нужно разложить по классам и CSS-переменным из ТЗ 1.
- Тексты черновые, Даня перепишет их сам. Отзывы пока заглушки в квадратных скобках.
- Шрифт Golos Text в прототипе грузится с Google Fonts. На сайте его лучше раздавать со своего сервера.
- Рекламная плашка, услуги, кейсы, отзывы и FAQ должны лежать в одном файле данных, чтобы Даня менял тексты без правки вёрстки (подробно в ТЗ 2).
- Страница услуги и страница кейса сделаны на одном примере. Остальные шесть услуг и пять кейсов собираются по этим шаблонам.
